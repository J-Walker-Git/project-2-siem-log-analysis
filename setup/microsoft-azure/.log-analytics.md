# Log Analytics Workspace Setup

The Log Analytics workspace was used as the central data store for collected logs in this lab. It allowed Microsoft Sentinel to ingest, query, and analyze Windows Security Events from the onboarded Windows 11 virtual machine (VM).

## Purpose

The Log Analytics workspace served as the location where security telemetry was stored before being queried in Sentinel. This is important because Microsoft Sentinel is onboarded to a Log Analytics workspace and uses that workspace for data collection and investigation workflows..

## Steps Completed

1. Signed in to the Azure portal.
2. Created a new Log Analytics workspace.
3. Selected the correct subscription, resource group, and region.
4. Linked Microsoft Sentinel to the workspace.
5. Used the workspace as the destination for collected Windows Security Events.

## Key Configuration Notes

The workspace needed to exist before Microsoft Sentinel could be enabled in the lab. After setup, it became the main location for reviewing ingested log data and running queries against the `SecurityEvent` table.
