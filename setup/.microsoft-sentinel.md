# Microsoft Sentinel

Microsoft Sentinel was the SIEM tool I used in this lab to collect, analyze, and investigate security events.

## Purpose

Sentinel was used to monitor the Windows 11 VM after onboarding it through Azure Arc. It helped confirm that security logs were flowing into the workspace and that failed logons could be queried and investigated.

## What was configured?

- Microsoft Sentinel was enabled on the Log Analytics workspace.
- A data connector was configured to collect Windows Security Events.
- Queries were run against the `SecurityEvent` table.
- Failed logon activity was reviewed to validate the lab setup.
