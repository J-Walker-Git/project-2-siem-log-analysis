# Azure Arc

Azure Arc was used to connect the Windows 11 virtual machine (VM) to Azure so it could be managed as a hybrid resource. This made it possible to onboard the VM into the lab environment even though it was not running froman external source outside of Azure.

## Purpose

The purpose of Azure Arc in this project was to bring the local Windows 11 VM under Azure management. Once connected, the VM could be targeted for agent deployment, monitoring configuration, and log collection.

## What was configured

- The Azure Arc onboarding script was generated in Azure.
- The script was run on the Windows 11 VM.
- The machine was connected as an Azure Arc-enabled server.
- The connected VM was then used for monitoring and security log collection.

## Issue

The script prepared by Azure Arc had several issues that caused conflicts with my Windows 11 VM.
Firstly the directory creation for the agent wasn't where it was expected to be after the installation.
Secondly the ServicePointManager was not required for Windows 11 due to it being legacy.
Thirdly the initial "Invoke-WebRequest" caused the script to exit before the installer download was even present.
Lastly the security software prevented the azcmagent service from starting so C:\ProgramFiles\AzureConnectedMachineAgent\ was temporarily disabled.

## Result

Azure Arc successfully connected the Windows 11 VM to Azure, allowing it to be managed and monitored as part of the Sentinel SOC lab.
