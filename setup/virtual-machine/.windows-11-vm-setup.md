# Windows 11 VM Installation

A Windows 11 virtual machine was installed in VMware Workstation Pro to serve as the endpoint for the SIEM lab. The VM was configured with the Windows 11 ISO, appropriate CPU, memory, and disk resources, then completed using the standard Windows setup wizard.

After installation, VMware Tools was installed and the VM was prepared for Azure Arc onboarding and log collection. This provided a clean test system for Sentinel monitoring and failed logon testing.
