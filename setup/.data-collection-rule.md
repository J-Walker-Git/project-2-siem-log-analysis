# Data Collection Rule

The Data Collection Rule (DCR) was used to define which events would be collected from the Windows 11 VM and sent to the Log Analytics workspace. In this lab, it was configured to collect Windows Security Events for use in Microsoft Sentinel.

## Purpose

The DCR acted as the collection policy for the Azure Monitor Agent. It determined what data would be gathered from the onboarded machine and where that data would be sent.

## What was configured

- A DCR was created in Azure.
- Windows Security Events were selected as the data source.
- The Log Analytics workspace was configured as the destination.
- The rule was associated with the onboarded Windows 11 VM.
