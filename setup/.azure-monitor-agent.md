# Azure Monitor Agent

The Azure Monitor Agent (AMA) was installed on the Windows 11 VM to collect telemetry from the operating system and send it to Azure through the configured Data Collection Rule.

## Purpose

The AMA was required to forward Windows event data from the VM to the Log Analytics workspace. This allowed Microsoft Sentinel to access and analyze the collected security logs.

## What was configured

- The AMA was deployed to the onboarded VM.
- The agent was linked to the Data Collection Rule.
- Windows Security Events were collected from the guest operating system.
- Data was forwarded to the Log Analytics workspace.
