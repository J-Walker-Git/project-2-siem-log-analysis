# Resource Group

The resource group was the container for the Azure resources used in the lab.

## Purpose

It kept the Log Analytics workspace, Microsoft Sentinel components, Azure Arc onboarding resources, and related settings organized in one place.

This made the project easier to manage, because all lab resources could be grouped, monitored, and deleted together when the exercise was finished. It also helped keep the environment clean and separated from any other Azure work.
